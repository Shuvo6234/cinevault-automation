# Privacy Policy

Last updated: October 3, 2026

CINEVAULT-AUTOMATION is a personal automation project used to upload authorized files to the owner's Google Drive account.

## Information We Access

The application may access Google Drive information necessary to perform file uploads and related operations.

The application does not sell, rent, or share Google user data with third parties for advertising or marketing purposes.

## Google Drive Data

Google Drive access is used only for the functionality requested by the owner of the application, including uploading files to the owner's designated Google Drive location and verifying uploaded files.

Google Drive data is not used for advertising, profiling, or unrelated purposes.

## Data Storage and Security

OAuth credentials and access tokens are stored securely using GitHub Actions Secrets and are not included directly in the application's source code.

The application does not intentionally make OAuth credentials publicly available.

## Data Sharing

We do not sell or transfer Google user data to third parties except where necessary to provide the requested functionality or where required by law.

## Data Retention

OAuth credentials and application data are retained only as necessary to operate the automation.

The owner may revoke the application's Google Drive access at any time through their Google Account security settings.

## Contact

For questions about this privacy policy, please contact the project owner through the contact information associated with this GitHub project.

## Changes to This Policy

This privacy policy may be updated when the application's functionality or data practices change.
